Live data connection

Finnhub quote + trade WebSocket
The app attempts Finnhub's trade WebSocket for tick events and REST quote snapshots for open/high/low/previous close. If your plan supports real-time trades for this symbol, updates arrive when the provider publishes trades. WebSocket does not mean millisecond exchange latency; the provider, exchange entitlement, internet and browser all add delay. Snapshot polling is rate-limited separately.
API key note: This is a static app. Your token is stored in this browser only, but browser-side keys can be inspected. Do not enter a paid secret key into a public deployment. For a public app, use a serverless proxy and keep the key server-side.
